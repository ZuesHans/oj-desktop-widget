# OJ Float Windows 版

安装包和免安装压缩包均包含完整 Flutter 客户端、轻量 C++ 题库小程序、浏览器扩展、猪猪一键存题脚本及必需运行库。支持 Windows 10 / 11 x64。

## 安装、升级和卸载

推荐运行 `OJ-Float-v0.2.0-windows-x64-setup.exe`。按当前用户安装，无需管理员权限；开始菜单包含两个程序和卸载入口，桌面快捷方式可选。升级时关闭两个程序，运行新版安装包覆盖原位置。

卸载默认保留 `%APPDATA%\ZuesHans\OJ Float` 中的题库、配置和训练记录。旧版 `%APPDATA%\com.example\oj_float` 会在首次启动校验后迁移，旧目录保留。若校验失败，请使用应用中的恢复页，避免手动覆盖原文件。设置底部可检查更新并打开官方下载页。

免安装用户需完整解压 zip。不要将任何 EXE 单独移出目录。发布页附带 SHA-256 校验文件；当前安装包未进行发布者代码签名。

## 完整客户端

运行 `oj_float.exe`。请不要把它单独移出本目录；Flutter 运行库和 `data` 目录是必需的。

首次引导可跳过。无需配置 OJ 账号即可保存题目、写笔记和安排待办。外观与功能自定义集中在设置中。

## 轻量题库与浏览器存题

1. 运行 `oj_problem_companion.exe`。
2. 在 Edge 安装 Tampermonkey。
3. 从 Tampermonkey 管理面板的“实用工具 → 从文件导入”选择
   `oj-float-importer.user.js`。
4. 浏览题目页面时点击右下角的猪头按钮。

油猴脚本只连接 C++ 小程序的 `127.0.0.1:27122` 服务，日常存题不需要保持
`oj_float.exe` 运行。若这台电脑还没有题库数据库，首次启动 C++ 小程序会短暂调用
同目录的 `oj_float.exe` 完成一次数据库迁移，之后即可独立运行。

不要单独复制 C++ EXE：`sqlite3.dll` 必须与它放在同一目录。

在主程序「设置 → 浏览器存题」可以检测题库小程序连接。浏览器扩展仍可连接主程序的 27121 入口，配对令牌按原说明配置。
