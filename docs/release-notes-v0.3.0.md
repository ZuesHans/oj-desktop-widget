# OJ Float v0.3.0 发布说明

发布日期：2026-10-24

本版本把「窗口状态与快捷操作」改进正式发布，并补齐诊断日志、仓库展示、发布链与许可说明。

## 窗口与快捷操作

- 主窗口记住大小、位置、最大化状态与上次停留页面，保存在本机 `window_state.json`；启动或显示器变化时检查屏幕工作区，越界自动回主屏居中。
- 快速录入临时小窗和最小化状态不会覆盖主窗口记录。
- 新增快捷键：`Ctrl+R` 刷新、`Ctrl+F` 打开补题页并聚焦搜索、`Ctrl+,` 打开设置、`Esc` 关闭当前弹窗或快速录入、`Ctrl+Shift+O` 全局快速录入（可改）。
- 模块关闭时对应快捷键自动停用；未保存设置离开前仍会确认。
- 打开快速录入时，剪贴板中的 OJ 题目链接自动填入链接栏；只有点击「解析」或「保存」才会发起请求，慢剪贴板不会覆盖手动输入。

## 诊断与隐私

- 启动早期安装全局错误捕获（框架错误与未处理异步错误），release 场景下也能留下可定位记录。
- 日志轮转：单文件上限 1 MiB、最多保留 5 个轮转文件；写入失败不会递归触发错误处理器，也不阻塞正常退出。
- 设置页新增「导出诊断信息」：先展示导出范围，再选择保存位置；导出纯本地、不自动上传。
- 默认不记录密码、Token、Cookie、请求头、原始响应、完整题库、笔记与复盘正文；OJ 账号、URL 账号/查询参数、绝对路径中的本机用户名按稳定别名脱敏。
- 详细字段与脱敏规则见 `docs/diagnostics.md`。

## 仓库与发布链

- README 增加真实截图（总览 / 题库 / 训练）与约 10 秒的浏览器存题演示（脚本驱动，已注明）；演示数据可复现，见 `docs/showcase-runbook.md`。
- GitHub description 与 topics 已更新（windows、flutter、competitive-programming、online-judge、codeforces、leetcode）。

- 发布资产增加构建来源证明（artifact attestation），绑定仓库、提交、workflow 与资产摘要；验证方法见 `docs/toolchain-upgrade.md`。
