OJ Float 的首个稳定版本：把题目、训练、待办与复盘集中在一个 Windows 工作台。

- 新增每用户安装包，统一安装完整客户端和轻量题库小程序，提供开始菜单入口、可选桌面快捷方式与卸载入口。附带 VC++ 运行库；卸载保留本地数据。
- 应用身份统一为 ZuesHans / OJ Float。首次升级将旧目录安全迁至 `%APPDATA%\ZuesHans\OJ Float`，保留旧目录；迁移失败进入恢复页，可修复后重试或选择有效备份恢复。
- 工作台沿用原有训练功能，统一文字与卡片排版。自定义集中在设置，支持模块开关、排序、宽度、明暗模式与配色预览；侧栏新增待办事项。
- 题库支持持久化空文件夹、多标签组合筛选和批量管理，保留收藏、置顶、笔记、题解、训练记录与计时。
- 题库小程序支持单实例恢复窗口；浏览器导入补齐错误长度、超大内容、慢请求、并发去重、端口占用与退出处理。设置可检测小程序连接。
- 新增可跳过的首次使用入口和手动检查更新。OJ 账号展示上次成功时间、失败原因与数据待更新状态。

推荐下载 `OJ-Float-v0.2.0-windows-x64-setup.exe`。免安装使用请选择完整 ZIP 并保留同目录的 DLL 与 `data`。下载文件的 SHA-256 见 `OJ-Float-v0.2.0-SHA256SUMS.txt`。

升级前建议导出一次完整备份，关闭旧版客户端与题库小程序后运行安装包。旧 JSON 题库、旧配置和数据库由新版主程序负责迁移；小程序不会独自修改数据库结构。若本地数据损坏，请使用启动恢复页，原始文件会保留在数据目录旁的 `before-restore` 文件夹。

安装包目前未作发行者代码签名，Windows 可能显示未知发行者。请从此仓库 Releases 下载并核对校验和。OJ 抓取依赖各平台公开接口与页面，网络或平台变更时会显示具体失败状态。
